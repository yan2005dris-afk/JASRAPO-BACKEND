
# NestJs

## Requisitos

- Node 22 - 24 Versiones LTS 
- npm 
- tener instalado cli NestJs

## Generar Modulos
NestJs permite generar modulos completos con el siguiente comando:

```bash
  nest g res nombreDelModulo
```

Esto generara una carpeta con el nombre que le hayamos puesto con lo siguiente:

- carpeta dto
- carpeta entity (no es necesario por prisma)
- archivos .spec.ts para controllers y services
- services
- controllers
- module
