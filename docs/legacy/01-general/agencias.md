# Agencias (Legacy)

## Campos

| Campo | Tipo | Descripción |
|-------|------|-------------|
| código | string | Código de la agencia |
| descripción | string | Nombre de la agencia |
| tipo | string | Tipo de agencia |
| activo | boolean | Estado del registro |

## Notas

- Las agencias representan las sedes o puntos de atención de la junta
- Se relaciona con las cajas (cada caja pertenece a una agencia)
