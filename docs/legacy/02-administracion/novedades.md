# Novedades Operativas (Legacy)

## Campos

| Campo | Tipo | Descripción |
|-------|------|-------------|
| descripción | string | Nombre de la novedad |
| activo | boolean | Estado |
| accion | string | Acción |

## Uso

- Se asignan a lecturas durante la toma
- Aparecen en el **estado de cuenta** como "nota de aviso"
- Se usan en el proceso de **cortes** como resultado de gestión
